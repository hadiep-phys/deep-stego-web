WEBSITE GIAU ANH AI: STREAMLIT COMMUNITY CLOUD + IFRAME
======================================================

BAN DAU: Khong can cai Python vao may de dua app len hosting.
Trang web HTML hien tai cua ban van la web tinh.

1. GIAI NEN BO FILE NAY
   Folder gom app.py, requirements.txt, .streamlit/config.toml,
   models/README.txt, iframe-example.html va .gitignore.

2. LAY FILE MODELS CU
   Trong du an PyTorch-Deep-Image-Steganography-master cu,
   copy 2 file sau vao folder models/ cua bo nay:
       models/HidingUNet.py
       models/RevealNet.py
   PHẢI dung dung 2 file tu du an da tao ra checkpoint.

3. TAO REPOSITORY GITHUB
   Vao https://github.com/new
   Repo name: deep-stego-web
   Chon Public -> Create repository.
   Chon Add file -> Upload files.
   Tai app.py, requirements.txt, thu muc models/ va .streamlit/config.toml
   len. Neu giao dien khong tai folder, tao thu cong cac file trong
   dung duong dan tuong ung tren GitHub.
   KHONG upload .venv, anh ca nhan, checkpoint .pth vao code repo.

4. UPLOAD 2 CHECKPOINT QUA GITHUB RELEASE
   Github repository -> Releases -> Create a new release
   Tag: v1.0, title: Model weights
   Tren may, tao BAN SAO cua 2 checkpoint co ten ngan:
       hnet.pth  (HidingNet ~167 MB)
       rnet.pth  (RevealNet ~3 MB)
   Keo hai file vao muc Attach binaries -> Publish release.
   Release assets co duong dan:
     https://github.com/TEN-GITHUB/deep-stego-web/releases/download/v1.0/hnet.pth
     https://github.com/TEN-GITHUB/deep-stego-web/releases/download/v1.0/rnet.pth
   Dung link that cua release assets. GitHub ma nguon co gioi han
   100 MiB; release assets cho phep file duoi 2 GiB.

5. TRIEN KHAI TREN STREAMLIT COMMUNITY CLOUD
   Vao https://share.streamlit.io -> dang nhap bang GitHub
   Create app -> Yup, I have an app.
   Repository: TEN-GITHUB/deep-stego-web
   Branch: main
   Main file path: app.py
   Advanced settings -> Python version: 3.11
   O Secrets, dan NOi DUNG sau (thay TEN-GITHUB):

HNET_URL = "https://github.com/TEN-GITHUB/deep-stego-web/releases/download/v1.0/hnet.pth"
RNET_URL = "https://github.com/TEN-GITHUB/deep-stego-web/releases/download/v1.0/rnet.pth"

   Save -> Deploy.

6. THU NGHIEM
   Mo ten-app.streamlit.app.
   Chon cover + secret -> Giau anh -> Tai Container.png.
   Chuyen sang tab Khoi phuc -> Tai len Container.png ->
   Khoi phuc anh -> Tai Revealed.png.

7. NHUNG VAO WEB HTML CU
   <iframe src="https://ten-app.streamlit.app/?embed=true"
           style="width:100%;height:850px;border:0"></iframe>

CAN CHU Y
- App can tai model AI len SERVER; anh cua nguoi dung CUNG DUOC
  chuyen den server de xu ly. Code khong co database va khong chu
  dong ghi anh nguoi dung ra file, nhung khong the bao dam ha tang
  hosting khong co tam thoi bo nho/ghi log.
- Hosting free co the thieu RAM hoac ngung hoat dong khi vang nguoi.
- Khong chay torch nightly Windows 3.15 tren Linux cloud: can moi
  truong 3.11 + CPU torch pin trong requirements.txt.
- Sao chep checkpoint .pth goc khi doi ten; khong xoa ban goc.
- HNET va RNET dung kiem tra ma nguon cu; khong phai LSB.
- Cac link GitHub Release phai public de server tai duoc.
- Su dung png cho anh Container, khong JPG.
